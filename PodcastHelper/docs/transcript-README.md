# Transcript

## Use Case

- Turn a transcript into headlines, description, show notes, and other podcast collaterial.

## Requirements

- Download and format a transcript from YouTube or podcast episode. User provides a URL, the script looks for a transcript to download into a Markdown file. USE VIDIQ.

## User Story

### From Transcript to Promotional

- User downloads transcript with VIDIQ. Playing the text into a Markdown file.
- Use the `transcript.py /path/to/transcript.md --media-file PXL_20260426_200955198.mp4` to digest transcript into a podcast sidecar containing collateral.
- User opens podcast sidecar to see YAML front matter extracted from filename, short description, list of headlines, and related note reference to transcript note.
